# Project Documentation Standard Rule

Whenever working on any project repository, automatically ensure the following structure exists:

1. **`doc/` Folder**: Create a dedicated `doc/` folder in the project root.
2. **`doc/ai_agent_instructions.md`**: Create a file containing comprehensive instructions, architecture overview, tech stack details, design system, and operational guidelines for AI agents working on this project.
3. **`doc/version.md`**: Create a file containing the project's version history, release notes, and change logs.
